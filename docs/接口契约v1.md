## 0. 公共约定

### 0.1 认证方式

所有需登录接口在 Header 中携带：
```
Authorization: Bearer <access_token>
```

### 0.2 错误码总表

| 错误码 | 含义 |
|--------|------|
| 200 | 成功 |
| 40001 | 用户名或密码错误 |
| 40002 | 参数验证失败 |
| 40003 | 账号已被禁用 |
| 40004 | 手机号已注册 |
| 40005 | 验证码错误或已过期 |
| 40101 | 未登录或Token过期 |
| 40102 | Token无效 |
| 40301 | 无权限访问 |
| 40401 | 资源不存在 |
| 40901 | 数据冲突（重复提交或状态已变更） |
| 50001 | 服务器内部错误 |
| 50002 | AI服务调用失败 |
| 50003 | 文件存储服务异常 |

### 0.3 分页参数

```
?page=1&page_size=20&sort_by=created_at&sort_order=desc
```

### 0.4 用户类型枚举

| 值 | 含义 |
|----|------|
| PROSPECT | 客户/访客 |
| STUDENT | 学生 |
| EMPLOYEE | 员工 |
| MANAGER | 管理层 |
| ADMIN | 管理员 |

### 0.5 客户状态枚举（6态）

| 值 | 含义 |
|----|------|
| NEW | 新录入 |
| FOLLOWING | 跟进中 |
| STRONG | 意向强烈 |
| SIGNED | 已签约 |
| ENROLLED | 已入学 |
| LOST | 已流失 |

### 0.6 审批业务类型枚举

| 值 | 含义 |
|----|------|
| leave | 请假 |
| convert | 留学生转化 |
| late_report | 日报补报 |
| complaint | 投诉处理 |

**AI 文字来源（v6.11.0 变更）**：`ai_source` 取值改为 `dify`=报告专用 Agent（经公共网关 `AgentType.REPORT`）/ `mock`=演示环境模拟（仅 `REPORT_DATA_SOURCE=mock`）/ `unavailable`=不可用。**production 下未配置报告专用 Agent 即判不可用，不回落模型网关、不复用其他业务 Agent**；`ai_status`（available/unavailable）语义不变

> **report_content 结构（v6.11.0）**：`header`（周期/版本/数据来源/数据截止/生成时间）、`metrics`、`summary/trend/analysis/suggestions`、`data_notes`、`data_quality`（各域 ok/empty/read_failed）、`data_unavailable`（各域不可得字段）、`comparison`（客户月报与上一自然月对比，`status=ok/unavailable/not_applicable`）。

> **期末状态（v6.11.0）**：M1 无历史时点能力时 `status_at_period_end=null`，依赖状态的指标（状态总览/新增去向/画像）标不可得，不用当前值冒充。

### GET /reports/{report_id}/psych_cases — 心理个案（快照；角色过滤：MANAGER/ADMIN 全量、EMPLOYEE 只看自己负责、其余 40301；仅 psych_weekly）
