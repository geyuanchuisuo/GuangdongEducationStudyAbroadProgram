## 0. 公共约定

### 0.1 认证方式

所有需登录接口在 Header 中携带：
```
Authorization: Bearer <access_token>
```

### 0.2 错误码总表

| 错误码 | 含义 |
|--------|------|
| 200 | 成功 |
| 40001 | 用户名或密码错误 |
| 40002 | 参数验证失败 |
| 40003 | 账号已被禁用 |
| 40004 | 手机号已注册 |
| 40005 | 验证码错误或已过期 |
| 40101 | 未登录或Token过期 |
| 40102 | Token无效 |
| 40301 | 无权限访问 |
| 40401 | 资源不存在 |
| 40901 | 数据冲突（重复提交或状态已变更） |
| 50001 | 服务器内部错误 |
| 50002 | AI服务调用失败 |
| 50003 | 文件存储服务异常 |

### 0.3 分页参数

```
?page=1&page_size=20&sort_by=created_at&sort_order=desc
```

### 0.4 用户类型枚举

| 值 | 含义 |
|----|------|
| PROSPECT | 客户/访客 |
| STUDENT | 学生 |
| EMPLOYEE | 员工 |
| MANAGER | 管理层 |
| ADMIN | 管理员 |

### 0.5 客户状态枚举（6态）

| 值 | 含义 |
|----|------|
| NEW | 新录入 |
| FOLLOWING | 跟进中 |
| STRONG | 意向强烈 |
| SIGNED | 已签约 |
| ENROLLED | 已入学 |
| LOST | 已流失 |

### 0.6 审批业务类型枚举

| 值 | 含义 |
|----|------|
| leave | 请假 |
| convert | 留学生转化 |
| late_report | 日报补报 |
| complaint | 投诉处理 |

### POST /employee/agent/chat — 企业助手会话（v6.5.0，权限感知 + 降级）

- **权限**：EMPLOYEE / MANAGER
- **请求体**：

```json
{
  "message": "帮我看看今天有什么要做",
  "session_id": "new"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| message | string | 是 | 用户消息（1~4000 字） |
| session_id | string | 否 | 会话 ID；不传或 `new` 表示新会话 |

- **权限感知注入**：后端按当前用户角色构建 Dify inputs（user_type / user_id / real_name / data_scope=own\|all / capabilities 能力清单），EMPLOYEE 仅名下数据 8 项能力，MANAGER 全域数据 14 项能力
- **响应 data**：

```json
{
  "reply": "……",
  "session_id": "conv-xxx",
  "source": "dify"
}
```

| source | 含义 |
|--------|------|
| dify | AI 网关正常返回（Dify EMPLOYEE Agent） |
| fallback | Dify 不可用，降级返回角色能力清单 + 指令式接口引导 |

- **多轮对话约定（v2.5.0 补记）**：后端透传 session_id（→Dify conversation_id）维持会话上下文，**后端不设轮次硬限制**；Dify EMPLOYEE Agent 记忆窗口建议配置 **5 轮**（覆盖指令式短链路场景；客户信息收集由多格式录入+注册表单承接，不依赖多轮问询；体验不足时仅需调整 Dify 侧配置）
- **意图边界约定（v2.5.0 补记）**：涉及薪资、人事任免等非授权指令，Agent 返回「权限不足/请联系HR」——EMPLOYEE Agent prompt 配置项，Dify 部署时落实

### POST /employee/commands/parse — 指令式业务解析（v6.1.3 交付，v2.8.3 补录+本地兜底）

- **权限**：EMPLOYEE / MANAGER
- **请求体**：`{ "text": "自然语言指令" }`
- **行为**：AI（EMPLOYEE Agent）解析优先；**AI 不可用/返回无效 JSON 时自动本地规则兜底（v2.8.3，不再返回 50002）**——本地兜底按关键词+正则识别 4 类常见句式，无法识别返回 40002 并附句式提示
- **响应 data**：

```json
// local 模式（默认）：file_url 为内部鉴权相对路径，前端经 axios（自动带 Bearer Token）访问
{ "object_name": "crm/2026-10-17/abc12345_file.pdf", "file_url": "/api/v1/files/download?object_name=crm/2026-10-17/abc12345_file.pdf" }
// s3 模式：file_url 为 MinIO 预签名 URL（浏览器可直连，默认 1 小时有效）
{ "object_name": "crm/2026-10-17/abc12345_file.pdf", "file_url": "http://minio:9000/education/crm/...?X-Amz-..." }
```

**object_name 规则**：`{module}/{YYYY-MM-DD}/{8位hex}_{原始文件名}`；服务端正则白名单+路径 resolve 双重校验，任何穿越/非法形态返回 50003。

#### GET /files/download?object_name=xxx — 下载文件（需登录）

- 成功：200 + `Content-Disposition: attachment; filename*=UTF-8''...` + 文件字节流
- object_name 非法/文件不存在：50003；未登录：40101/40102

#### GET /files/presigned?object_name=xxx — 获取下载地址（需登录）

- local 模式：返回内部鉴权下载端点相对路径（语义为"下载地址"，非免登录直链）
- s3 模式：返回 MinIO 限时预签名 URL（expires_hours 默认 1）

### 8.4 操作日志查询（v6.6.0 已实现，提前落地 Phase 1.3 规划）

#### GET /operation-logs — 操作日志列表（MANAGER）

**需求依据**：员工业务需求 v2 管理层「操作日志：关键操作留痕（客户状态变更/审批/权限调整）」

**Query 参数**：`action_type`（操作类型，如 customer_status_change/customer_reassign/phone_reveal）/ `operator_id`（操作人）/ `start` / `end`（时间范围，含当天）/ page / page_size

**写入侧**：客户状态变更（customer_status_change）、客户再分配（customer_reassign）、电话查看（phone_reveal）均写 sys_operation_log

### 8.5 事件总线（内部接口，不对外暴露）

事件通过 `event_bus.publish()` 在代码内部发布，不通过 HTTP 接口。
