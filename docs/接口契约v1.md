# 接口契约 v2

> **版本**：v2.0.0  
> **日期**：2026-10-16  
> **Base URL**：`/api/v1`  
> **变更说明**：新增 customer 客户主表、审批引擎升级为双表设计

**统一响应格式**：

```json
{
  "code": 200,
  "message": "success",
  "data": {},
  "traceId": "abc12345",
  "timestamp": 1697450000
}
```

---

## 0. 公共约定

### 0.1 认证方式

所有需登录接口在 Header 中携带：
```
Authorization: Bearer <access_token>
```

### 0.2 错误码总表

| 错误码 | 含义 |
|--------|------|
| 200 | 成功 |
| 40001 | 用户名或密码错误 |
| 40002 | 参数验证失败 |
| 40003 | 账号已被禁用 |
| 40004 | 手机号已注册 |
| 40005 | 验证码错误或已过期 |
| 40101 | 未登录或Token过期 |
| 40102 | Token无效 |
| 40301 | 无权限访问 |
| 40401 | 资源不存在 |
| 40901 | 数据冲突（重复提交或状态已变更） |
| 50001 | 服务器内部错误 |
| 50002 | AI服务调用失败 |
| 50003 | 文件存储服务异常 |

### 0.3 分页参数

```
?page=1&page_size=20&sort_by=created_at&sort_order=desc
```

### 0.4 用户类型枚举

| 值 | 含义 |
|----|------|
| PROSPECT | 客户/访客 |
| STUDENT | 学生 |
| EMPLOYEE | 员工 |
| MANAGER | 管理层 |
| ADMIN | 管理员 |

### 0.5 客户状态枚举（6态）

| 值 | 含义 |
|----|------|
| NEW | 新录入 |
| FOLLOWING | 跟进中 |
| STRONG | 意向强烈 |
| SIGNED | 已签约 |
| ENROLLED | 已入学 |
| LOST | 已流失 |

### 0.6 审批业务类型枚举

| 值 | 含义 |
|----|------|
| leave | 请假 |
| convert | 留学生转化 |
| late_report | 日报补报 |
| complaint | 投诉处理 |

## 1. 认证模块（M0）

### POST /auth/login — 登录

**请求**：
```json
{ "username": "string", "password": "string" }
```
**响应 data**：
```json
{
  "access_token": "string",
  "user_id": 1,
  "username": "admin",
  "real_name": "管理员",
  "user_type": "ADMIN"
}
```

### POST /auth/register — 注册

**请求**：
```json
{
  "username": "string",
  "password": "string",
  "real_name": "string",
  "user_type": "PROSPECT | STUDENT",
  "contact_info": "string (可选)"
}
```
**响应 data**：
```json
{ "user_id": 1, "username": "newuser" }
```

## 8. 公共基础设施接口（M0）

### 8.1 审批引擎 — v2.0 升级（双表设计）

#### POST /approvals — 创建审批单

**请求**：
```json
{
  "biz_type": "leave | convert | late_report | complaint",
  "biz_id": 123,
  "title": "张三请假申请",
  "approver_id": 5
}
```

**响应 data**：
```json
{
  "id": 1,
  "biz_type": "leave",
  "biz_id": 123,
  "title": "张三请假申请",
  "initiator_id": 10,
  "status": "pending",
  "current_step": 1,
  "total_steps": 1,
  "finished_at": null,
  "created_at": "2026-10-16T00:00:00",
  "tasks": [
    {
      "id": 1,
      "instance_id": 1,
      "approver_id": 5,
      "seq_no": 1,
      "action": null,
      "comment": null,
      "status": "pending"
    }
  ]
}
```

#### POST /approvals/{instance_id}/approve — 审批通过

**请求**：`{ "comment": "同意" }`

#### POST /approvals/{instance_id}/reject — 审批拒绝

**请求**：`{ "comment": "不同意，原因..." }`

#### POST /approvals/batch-approve — 批量审批通过

**请求**：
```json
{
  "instance_ids": [1, 2, 3],
  "comment": "批量通过"
}
```

#### GET /approvals/pending — 待审批列表

#### GET /approvals/my — 我发起的审批

#### GET /approvals/{instance_id} — 审批详情

### 8.2 通知中心

#### GET /notifications — 通知列表

**查询参数**：`?type=&unread_only=true&page=1&page_size=20`

#### GET /notifications/unread-count — 未读数量

#### PUT /notifications/{id}/read — 标记已读

#### PUT /notifications/read-all — 全部标记已读

### 8.3 文件存储

#### POST /files/upload — 上传文件

**请求**：`multipart/form-data`
- `module`: crm | cs | employee | student | report | system
- `file`: 文件（<= 20MB，白名单类型）

**响应 data**：
```json
{ "object_name": "crm/2026-10-16/abc123_file.pdf", "file_url": "https://..." }
```

#### GET /files/download?object_name=xxx — 下载文件

#### GET /files/presigned?object_name=xxx — 获取预签名URL

### 8.4 事件总线（内部接口，不对外暴露）

事件通过 `event_bus.publish()` 在代码内部发布，不通过 HTTP 接口。
