## 一、项目概述

### 1.1 项目背景

广东省教育服务有限公司（简称"粤教服务"）创办于1981年，2024年3月划转至广东教育国际交流服务中心有限公司（简称"粤教国际"）。公司主营业务包括国际教育、智慧教育、素质教育和实体教育。

核心业务线：
- **德国双元制职业教育项目**：中德精英人才共建计划
- **新加坡国际本硕升学项目**：定向培养联合办学项目
- **国际留学项目**：全球数百所院校合作
- **国际研学项目**：面向中小学生、高职高专及大学生

### 1.2 项目目标

构建一个智能化的教育服务管理平台，实现：
1. **留学生智能管家**：为学生提供AI驱动的行政服务、心理健康监测、售后反馈
2. **企业员工智能助手**：为员工提供CRM客户管理、日报管理、成绩管理等AI辅助工具
3. **客服与活动管理**：智能客服、课程项目管理、活动报名管理
4. **传统业务功能**：用户管理、权限控制、业务流程管理、知识库管理

### 1.3 用户角色

| 角色 | 描述 | 核心功能 |
|------|------|----------|
| 学生（STUDENT） | 初中/高中/专科/本科毕业生 | 请假申请、考务查询、心理测评、反馈提交、课程报名 |
| 员工（EMPLOYEE） | 普通员工/领导/管理员 | CRM管理、日报提交、成绩录入、客户跟进、审批处理 |
| 客户（CUSTOMER） | 意向客户/已签约客户 | 活动报名、课程咨询、资料查询 |
| 管理员（ADMIN） | 系统管理员 | 用户管理、权限配置、系统监控、数据导出 |

## 三、系统分层设计

### 3.1 API路由层（api/）

**职责**：
- 接收HTTP请求
- 参数验证（Pydantic）
- 调用Service层
- 返回统一响应格式

**规范**：
```python
# 统一响应格式
{
    "code": 200,          # 业务状态码
    "message": "success", # 提示信息
    "data": {},           # 响应数据
    "timestamp": 1697270400  # 时间戳
}

# 错误响应格式
{
    "code": 40001,        # 错误码
    "message": "用户名或密码错误",
    "data": None,
    "timestamp": 1697270400
}
```

**示例代码**：
```python
# app/api/v1/auth.py
from fastapi import APIRouter, Depends
from app.schemas.user import LoginRequest, LoginResponse
from app.services.user_service import UserService
from app.core.response import success_response

router = APIRouter(prefix="/auth", tags=["认证"])

@router.post("/login")
async def login(
    request: LoginRequest,
    service: UserService = Depends()
):
    """用户登录"""
    result = await service.login(request)
    return success_response(data=result, message="登录成功")
```

### 3.2 业务逻辑层（services/）

**职责**：
- 实现核心业务逻辑
- 调用Repository层
- 事务管理
- 业务规则校验

**规范**：
- 一个Service对应一个业务模块
- 方法命名：动词+名词（如：create_user, get_user_by_id）
- 异常统一抛出自定义异常

**示例代码**：
```python
# app/services/user_service.py
from app.repositories.user_repo import UserRepository
from app.core.exceptions import BusinessError
from app.core.security import verify_password, create_access_token

class UserService:
    def __init__(self, repo: UserRepository):
        self.repo = repo
    
    async def login(self, request: LoginRequest) -> LoginResponse:
        """用户登录"""
        # 1. 查询用户
        user = await self.repo.get_by_username(request.username)
        if not user:
            raise BusinessError(code=40001, message="用户名或密码错误")
        
        # 2. 验证密码
        if not verify_password(request.password, user.password_hash):
            raise BusinessError(code=40001, message="用户名或密码错误")
        
        # 3. 检查状态
        if user.status != "正常":
            raise BusinessError(code=40003, message="账号已被禁用")
        
        # 4. 生成Token
        token = create_access_token({"sub": user.id, "type": user.user_type})
        
        return LoginResponse(
            access_token=token,
            user_id=user.id,
            username=user.username,
            real_name=user.real_name,
            user_type=user.user_type
        )
```

### 3.3 数据访问层（repositories/）

**职责**：
- 数据库CRUD操作
- SQL查询封装
- 数据缓存策略

**规范**：
- 一个Repository对应一个数据表
- 方法命名：get_by_xxx, create, update, delete
- 复杂查询使用SQLAlchemy表达式

**示例代码**：
```python
# app/repositories/user_repo.py
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession
from app.models.user import User

class UserRepository:
    def __init__(self, db: AsyncSession):
        self.db = db
    
    async def get_by_username(self, username: str) -> User | None:
        """根据用户名查询用户"""
        result = await self.db.execute(
            select(User).where(User.username == username)
        )
        return result.scalar_one_or_none()
    
    async def create(self, user: User) -> User:
        """创建用户"""
        self.db.add(user)
        await self.db.commit()
        await self.db.refresh(user)
        return user
```

## 四、数据库设计

### 4.1 核心表结构

#### 4.1.1 统一用户表（sys_user）

```sql
CREATE TABLE sys_user (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    real_name VARCHAR(50) NOT NULL,
    user_type VARCHAR(20) NOT NULL CHECK (user_type IN ('STUDENT', 'EMPLOYEE')),
    employee_role VARCHAR(50),
    department VARCHAR(100),
    contact_info TEXT,
    status VARCHAR(20) DEFAULT '正常' CHECK (status IN ('正常', '禁用')),
    create_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    update_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 索引
CREATE INDEX idx_user_username ON sys_user(username);
CREATE INDEX idx_user_type ON sys_user(user_type);
CREATE INDEX idx_user_department ON sys_user(department);
```

**字段说明**：
| 字段 | 类型 | 说明 | 约束 |

| username | VARCHAR(50) | 登录账号 | 唯一，非空 |
| password_hash | VARCHAR(255) | 加密密码 | 非空 |
| real_name | VARCHAR(50) | 真实姓名 | 非空 |

| employee_role | VARCHAR(50) | 员工角色 | 普通员工/领导/管理员 |

### 6.3 API请求封装

```typescript
// frontend/src/utils/request.ts
import axios, { AxiosInstance, AxiosRequestConfig } from 'axios';
import { ElMessage } from 'element-plus';
import { useUserStore } from '@/stores/user';

const service: AxiosInstance = axios.create({
    baseURL: import.meta.env.VITE_API_BASE_URL || '/api/v1',
    timeout: 30000,
});

// 请求拦截器
service.interceptors.request.use(
    (config) => {
        const userStore = useUserStore();
        if (userStore.token) {
            config.headers.Authorization = `Bearer ${userStore.token}`;
        }
        return config;
    },
    (error) => Promise.reject(error)
);

// 响应拦截器
service.interceptors.response.use(
    (response) => {
        const res = response.data;
        if (res.code !== 200) {
            ElMessage.error(res.message || '请求失败');
            
            // Token过期
            if (res.code === 40101) {
                const userStore = useUserStore();
                userStore.logout();
                window.location.href = '/login';
            }
            
            return Promise.reject(new Error(res.message));
        }
        return res;
    },
    (error) => {
        ElMessage.error(error.message || '网络错误');
        return Promise.reject(error);
    }
);

export default service;
```

```vue
    apiEndpoint: string;
}

const inputMessage = ref('');
const conversationId = ref('');

const handleSend = async () => {
    if (!inputMessage.value.trim()) return;
    
    // 添加用户消息
    messages.value.push({
        id: Date.now(),
        role: 'user',
        content: inputMessage.value,
    });
    
    try {
        // 调用AI接口
        const response = await fetch(props.apiEndpoint, {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({
                message: inputMessage.value,
                conversation_id: conversationId.value,
            }),
        });
        
        const data = await response.json();
        
        // 添加AI回复
        messages.value.push({
            id: Date.now() + 1,
            role: 'assistant',
            content: data.data.answer,
        });
        
        conversationId.value = data.data.conversation_id;
        inputMessage.value = '';

    } catch (error) {

    }
};
```

```python
from datetime import datetime, timedelta
from jose import jwt
from passlib.context import CryptContext
from app.config import settings

pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")

def verify_password(plain_password: str, hashed_password: str) -> bool:
    return pwd_context.verify(plain_password, hashed_password)

def get_password_hash(password: str) -> str:
    return pwd_context.hash(password)

def create_access_token(data: dict) -> str:
    to_encode = data.copy()
    expire = datetime.utcnow() + timedelta(minutes=settings.ACCESS_TOKEN_EXPIRE_MINUTES)
    to_encode.update({"exp": expire})
    return jwt.encode(to_encode, settings.SECRET_KEY, algorithm=settings.ALGORITHM)
```

```python
from fastapi import Request, HTTPException
from app.core.security import decode_access_token

async def auth_middleware(request: Request, call_next):
    # 白名单路径
    whitelist = ["/api/v1/auth/login", "/api/v1/auth/register"]
    if request.url.path in whitelist:
        return await call_next(request)
    
    # 验证Token
    token = request.headers.get("Authorization", "").replace("Bearer ", "")
    if not token:
        raise HTTPException(status_code=401, detail="未登录")
    
    payload = decode_access_token(token)
    if not payload:
        raise HTTPException(status_code=401, detail="Token无效或过期")
    
    # 将用户信息存入request.state
    request.state.user_id = payload["sub"]
    request.state.user_type = payload["type"]
    
    return await call_next(request)
```
