| **影响范围** | 全部 API（外键类型不匹配导致建表失败；中间件 Content-Length 错误导致所有 JSON 响应崩溃；异常处理器返回 dict 导致 500；JWT sub 类型错误导致鉴权失败；bcrypt 5.x 不兼容导致登录崩溃；种子脚本字段名不匹配） |
| **排查过程** | 1. 启动 uvicorn 报 MySQL 3780 → 定位 12 处 BigInteger 外键 vs sys_user.id Integer<br>2. 建表通过后请求任一 JSON 接口报"Response content longer than Content-Length" → 中间件注入 traceId 后未重算<br>3. 业务异常返回 500 "TypeError: 'dict' object is not callable" → 异常处理器返回 dict 而非 Response<br>4. 登录接口报 bcrypt ValueError → bcrypt 5.0.0 与 passlib 1.7.4 不兼容<br>5. seed_data.py 报 TypeError/IntegrityError → 9 处字段名/唯一约束与模型不匹配<br>6. 登录返回 200 但 /users/me 40101 → python-jose 新版要求 sub 必须是字符串 |

| **教训总结** | 1. Phase 0 完成必须以"真实启动+真实请求+真实数据"为验收标准，离线断言不够<br>2. 修改中间件/异常处理器/安全模块必须全链路验证<br>3. SQLAlchemy 外键类型必须与引用列严格一致（Integer vs BigInteger）<br>4. 第三方库主版本升级（bcrypt 5.x）必须人工锁定兼容范围<br>5. 种子脚本必须与模型同步演进，模型变更时同步检查种子 |

## 常见问题速查

### 数据库相关

**Q: 数据库连接失败？**
- 检查MySQL服务是否启动（端口59000）
- 检查DATABASE_URL配置
- 检查用户名密码
- 检查数据库是否已创建

**Q: 数据库迁移失败？**
- 检查Alembic配置
- 检查迁移脚本
- 查看错误日志

### API接口相关

**Q: 接口返回401未授权？**
- 检查Token是否有效
- 检查Token是否过期
- 检查Authorization头格式

**Q: 接口返回403无权限？**
- 检查用户角色
- 检查权限配置
- 检查中间件逻辑

### 前端相关

**Q: 跨域问题？**
- 开发环境：配置vite proxy
- 生产环境：配置Nginx反向代理

**Q: 页面加载慢？**
- 检查网络
- 检查接口响应时间
- 检查资源大小
- 开启gzip压缩

### AI能力相关

**Q: Dify接口调用失败？**
- 检查DIFY_BASE_URL
- 检查API Key
- 检查Agent是否已发布
- 检查网络连接

**Q: AI回答不准确？**
- 检查知识库文档质量
- 优化Prompt
- 调整检索策略
- 增加知识库内容
