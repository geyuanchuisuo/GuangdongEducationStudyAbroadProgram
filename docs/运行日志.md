## 常见问题速查

### 数据库相关

**Q: 数据库连接失败？**
- 检查MySQL服务是否启动（端口59000）
- 检查DATABASE_URL配置
- 检查用户名密码
- 检查数据库是否已创建

**Q: 数据库迁移失败？**
- 检查Alembic配置
- 检查迁移脚本
- 查看错误日志

### API接口相关

**Q: 接口返回401未授权？**
- 检查Token是否有效
- 检查Token是否过期
- 检查Authorization头格式

**Q: 接口返回403无权限？**
- 检查用户角色
- 检查权限配置
- 检查中间件逻辑

### 前端相关

**Q: 跨域问题？**
- 开发环境：配置vite proxy
- 生产环境：配置Nginx反向代理

**Q: 页面加载慢？**
- 检查网络
- 检查接口响应时间
- 检查资源大小
- 开启gzip压缩

### AI能力相关

**Q: Dify接口调用失败？**
- 检查DIFY_BASE_URL
- 检查API Key
- 检查Agent是否已发布
- 检查网络连接

**Q: AI回答不准确？**
- 检查知识库文档质量
- 优化Prompt
- 调整检索策略
- 增加知识库内容
