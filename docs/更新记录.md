| **影响范围** | 全局（用户体系、权限体系、页面设计、Agent设计、数据库、业务流程） |
| **修改文件** | docs/项目需求文档.md, docs/AGENTS.md, docs/更新记录.md |
| **效果** | 5角色体系覆盖完整业务链路：意向客户自行注册→员工开通→转化为留学生→员工审批流程→管理层按人分配权限→系统管理员全局管控 |
| **负责人** | 开发团队 |
| **审核状态** | 待审核 |

**详细变更**：
1. **角色重构** - 取消ADMIN业务角色（保留测试用），4个业务角色：PROSPECT/STUDENT/EMPLOYEE/MANAGER
2. **新增管理层角色** - 含经理/总裁，系统管理员逐人分配权限；二期拆分人事、经理、总裁
3. **新增permissions字段** - sys_user表新增JSON类型permissions字段，仅MANAGER使用
4. **新增"待开通"状态** - 意向客户自行注册后状态为"待开通"，需员工审核开通
5. **新增公开主页设计** - 无需登录即可访问，含7大场景智能客服Agent置顶
6. **新增注册字段定义** - 必填（姓名/性别/年龄/联系方式/学历）+ 选填（家庭经济/职业需求/德语能力）
7. **新增登录后页面设计** - 按角色分述（普通员工/经理总裁/留学生），含完整导航页功能列表
8. **新增3个Agent详细设计** - 智能客服（主动信息采集）、企业助手（权限感知+数据隔离）、学生助手（心理关怀+限制预期）
9. **新增客户信息采集三渠道** - 自行注册/员工录入/管理层录入，支持多格式（文字/PDF/照片/Word/Excel/Agent对话）
10. **新增有效性判断规则** - 电话号码为唯一有效性标准；客户重复按电话号码去重
11. **新增留学生转化审批** - 员工申请 → 经理审批
12. **新增员工数据隔离** - 普通员工只能看自己名下客户，管理层可变更归属
13. **新增站内消息表** - sys_notification，支持审批结果/待办/学业/心理预警等通知
14. **新增消息通知机制** - 站内消息 + Agent主动推送
15. **新增口述日报格式** - AI自动整理成结构化日报（今日工作/明日计划/问题反馈）
16. **新增指令式业务处理** - 需二次确认后执行
17. **新增活动报名规则** - 需注册登录后报名，未登录跳转登录页
18. **新增留学生管理7子模块** - 行政服务/心理关怀/售后反馈/学业考务/进度追踪/生活支持/更多服务
19. **新增一期/二期范围划分** - 一期核心业务闭环（15周），二期扩展功能（人事拆分/心理量表/NL2SQL）
20. **新增5项待确认事项** - 置于文档最上方，待客户确认后纳入最终版
21. **数据库表从16张增至17张** - 新增sys_notification
22. **种子数据更新** - 测试用系统管理员+总裁+员工+留学生+意向客户
