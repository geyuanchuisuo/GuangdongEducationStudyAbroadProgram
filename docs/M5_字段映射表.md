### 4.1 投诉域（M4）——❌ 阻塞，缺 9 字段

`student_feedback_ticket` 现有字段仅：id / student_id / content / detail / status(待处理等中文值) / solution / is_notified / create_time / update_time。

| 报告所需字段 | 现状 | 说明 |
|---|---|---|
| feedback_type | ❌ 无 | 无法区分投诉/建议/咨询（统计对象口径的前提） |
| first_response_at | ❌ 无 | 首次响应时长、未响应计数不可算 |
| resolved_at | ❌ 无 | 周期内解决数不可算（现 status 为中文枚举，与 open/resolved 也不对应） |
| 满意度 | ❌ 无 | 满意/不满意/未评价 |
| review_status | ❌ 无 | 特别案例复核流程 |
| ai_high_risk / ai_low_score | ❌ 无 | 特别案例候选判定 |
| owner_id | ❌ 无 | 案例负责人 |
| progress | ❌ 无 | 处理进度 |

**结论**：`REPORT_DATA_SOURCE=production` 下投诉周报拒绝生成（提示数据域不可得），不填零、不回落 mock。需 M4 负责人改表+迁移（字段名与复核流程见《02_一期指标口径表V1》待确认项 4），M5 只消费。

### 4.2 客户状态历史（M1）——⚠️ 近似口径

customer.status 只有当前值，无变更流水。「期末状态」「回流不计新增」当前按**当前状态推算**，报告数据说明中如实标注。精确口径需 M1 提供状态快照或事件流水（口径表待确认项 1）。

### 4.3 画像 4→3 映射（业务拍板项）

研判结论值域（代码 SCORE_BY_CONCLUSION）：matched / partial / pending / not_matched。

| 研判值 | 当前保守映射 | 待拍板 |
|---|---|---|
| matched | 符合 | — |
| not_matched | 不符合 | — |

## 五、权限与隐私（M5-09 相关，取数侧约束）

- 适配器只读；不越权取个人明细进报告（报告仅聚合）
- 心理个案下钻仍按报告周期过滤 + 角色过滤（MANAGER/ADMIN 全部、EMPLOYEE 仅自己负责、其余 403）
