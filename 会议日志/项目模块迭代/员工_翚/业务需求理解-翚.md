# 粤教留学项目 - 项目需求整理
1. 后台系统用户角色：
	1. 意向客户：陌生访客、意向客户、还没有和公司业务往来的访客，过来了解公司业务
	2. 留学生：公司主要的业务就是帮助客户成为留学生
	3. 员工：公司工作人员，可以录入客户给客户申请成为留学生，审批学生提交的流程等
	4. 管理层：公司管理人员，不同管理层可选择开放不同权限，审批员工提交的流程等
	5. 系统管理员：整个系统管理员，可以进行所有用户的管理、权限配置等
2. 主要界面模块
	1. 主页（无需登录即可访问）
		1. 意向客户
			1. 主页面
			2. 导航页
				1. 公司信息咨询、公司业务查询、海外留学政策查询、课程与项目推荐、活动与讲座报名、常见问题自助解答、日常闲聊互动
					1. 支持年轻化人设和个性化推荐
				2. 用户登录模块 - 可自行注册（功能权限需由员工开通）
					1. 注册时：
						1. 必填信息：姓名、性别、年龄、联系方式、学历
						2. 选填信息：家庭经济状况、职业需求、德语能力
					2. 登陆后：浏览课程/活动、提交咨询
			3. ==智能客服agent== 窗口置顶、随时等待客户调用
				1. 要主动咨询客户感兴趣的内容，以此判断客户是否意向客户
				2. 咨询过程中要了解客户信息，比如姓名、性别、年龄、联系方式、学历、家庭经济基础、职业需求、德语能力等
	2. 登陆后页面（需要账户鉴权）
		1. 员工
			1. 主页面
			2. 导航页
				1. 意向客户录入（员工CRM管理）、意向客户查询、客户状态更新、代客户申请留学生、审批学生流程（如请假）、成绩录入、口述日报、日报查看、组织架构查询、新人指引、主动待办推送、指令式业务处理
					1. 这些哪一些要合并，哪一些要单拿出来
			3. ==企业智能助手agent== 窗口置顶、提醒员工未达成任务
			4. 个人信息页面
		2. 留学生
			1. 主页面
			2. 导航页
				1. 行政服务（请假）、心理关怀（情绪疏导+预警）、售后反馈、学业考务、进度追踪、生活支持、更进一步（增值转化：这是业务面的说法，这个字段在学生界面得换掉）
			3. ==学生智能助手agent== 窗口置顶、对学生进行心里关怀、提示词要限制预期
			4. 个人信息页面
		3. 管理层
			1. 主页面
			2. 导航页
				1. 基础管理功能 + 系统管理员开放的具体权限（如审批员工流程、查看报告、查看全部客户等）
				2. 最高权限有哪些：
					1. 经营看板（全域客户经营分析报告）、员工日报汇总报告（日）、员工日报汇总报告（周）、学生信息健康周报、投诉处理周报、审批员工流程、全部客户查询、
			3. ==企业智能助手agent（这个和员工的是一回事吗？）== 客服窗口置顶、主动推送经营状况、数据分析等。
			4. 个人信息页面
		4. 系统管理员
			1. 主页面
			2. 导航页
				1. 全部权限：用户管理、权限配置（给管理层分配权限）、系统监控、数据导出
			3. ==智能客服agent==
				1. 系统管理员需不需要这个 agent ，或者他这个窗口应该接哪个权限的agent
				2. 我们开发完交付之后，这个系统管理员应该是对方公司的员工，他的权限有多大
			4. 个人信息页面
	3. 业务流程
		1. 意向客户自行注册 
			1. → 员工审核并开通功能权限
			2. → 员工将意向客户转化为留学生（user_type: PROSPECT → STUDENT） 
			3. → 留学生使用平台服务（请假、考务、反馈等）
			4. → 负责的员工审批留学生提交的流程
		2. 管理层权限由系统管理员逐人配置（JSON权限列表）
		3. 系统管理员拥有全部权限，不受权限列表限制
3. 数据库
	1. 客户咨询在了解过程中不会那么全面，有的客户不愿意透露名称、有的客户不愿意透露联系方式，这些是否都要进行录入，或者有虚假信息，怎么判别
	2. 那如果有一部分是有效信息，比如这个客户了解完之后，只告诉了一个电话号码，其他的都没有说，怎么录入信息，怎么分配给业务，要不要加==客户意向==字段
	3. 这个基础表不能有太多的录入限制，因为很有可能信息不完全，但是怎么判断有效信息
		1. 这个部分要看录入之前怎么过滤，通过什么判断是一个有效信息（==电话号码？==）
4. 客户研判规则
	1. 新加坡国际本硕升学计划用户画像规则
		1. 用户画像：
			1. 初中学历：对应初中毕业生群体，可参与2 + 2及2 + 2 + 1学制项目。
			2. 高中学历（含中职、中技等同等学历）：包括高二在读、应往届高中毕业生，以及中职、中技毕业生，可参与0.5/1 + 2及0.5/1 + 2 + 1学制项目。
			3. 专科学历：国内专科毕业生，可考虑一年制专升本项目。
			4. 本科学历：国内本科毕业生，可关注一年制本升硕项目。
			5. 大专学历（职高、中专、中职、技校毕业获得的大专文凭）：通过6 + 6酒店运营大专就业班和9 + 6航空运营大专就业班可获得相应大专文凭。
		2. 招生范围
			1. **国内范围**
				1. 项目面向全国招生，包括全国范围内的初中毕业生、高二在读及高中毕业生、职高、中专、中职、技校学生等，无明显的地域限制。
		3. 费用
			1. 四年学费总计约30 - 31万人民币，部分项目如0.5/1 + 2国际本科班学费总计约25 - 26万人民币，还有公费0学费留学的情况
	2. 中德精英人才共建计划
		1. 基本属性
			1. 年龄
				1. 18 - 35岁
			2. 学历
				1. 高中及以上学历
		2. 社会属性
			1. 职业需求
				1. ​​就业导向：项目强调保就业
				2. ​​升学需求：项目提供可升学的途径
				3. ​​移民需求：项目提到工作两年后可申请德国永居
			2. 技能需求​​
				1. ​​动手能力强：培训生需要在企业接受职业技能方面的专业培训
				2. 逻辑思维强：无论是企业实践还是职业学校的专业课程学习，都需要一定的逻辑思维能力来理解和掌握知识，解决实际问题
			3. 语言能力​​
				1. ​​有一定德语学习能力和表达能力：要求有一定德语学习能力和表达能力，并且需要在国内考取德语B1后才能匹配德国企业并进行面试
		3. 家庭背景与经济状况​​
			1. 家庭支持：潜在客户可能需要有一定的家庭经济基础或家庭支持，以确保能够顺利完成职业培训。
			2. 经济理性：潜在客户可能更注重教育投资的性价比和回报。
	3. 用户研判完之后，输出字段：
		1. 姓名、性别、年龄、联系方式、学历、家庭经济基础、职业需求、德语能力
5. 公司给客户提供服务

		2. 中德精英人才共建计划
