# 智能报告模块一期执行资料包

版本：V1.0
状态：一期方案基线，待开发执行
适用项目：粤教留学项目管理平台

## 文件清单

1. `01_五类报告样稿V1.md`：五类报告的页面、PDF和下钻结构。
2. `02_一期指标口径表V1.md`：已确认的业务口径、技术默认规则和待确认项。
3. `03_模拟数据设计与验证方案V1.md`：模拟数据结构、样本场景、预期结果和真实数据替换边界。
4. `04_智能报告模块详细执行方案V1.md`：分阶段执行顺序、模块边界、验收标准和风险。
5. `05_交给其他Agent的执行提示词.md`：可直接复制给其他Agent执行的任务提示词。

## 使用顺序

1. 先读本说明和 `04_智能报告模块详细执行方案V1.md`。
2. 再读 `01`，确定报告展示结构。
3. 再读 `02`，所有“已确认”规则直接执行；“待确认”规则不得擅自补充业务含义。
4. 再读 `03`，先用模拟数据跑通完整流程。
5. 最后把 `05` 中的提示词交给其他Agent。不同Agent负责不同阶段，禁止多个Agent同时修改同一组文件。

## 当前一期边界

- 先用模拟数据跑通，不等待M1-M4真实模块完成。
- 后续只替换数据来源适配层，报告统计、展示、权限和导出逻辑尽量不变。
- 一期手动生成报告；暂不做自动定时生成。
- 一期支持网页查看和PDF下载；暂不做Word、Excel。
- 一期报告整体只开放给MANAGER；心理个案按授权范围单独下钻。
- AI只做摘要、归纳、趋势说明、风险提示和建议；程序负责所有数字和规则判断。
- 未确认的业务规则必须标记，不能使用默认值冒充业务决定。
