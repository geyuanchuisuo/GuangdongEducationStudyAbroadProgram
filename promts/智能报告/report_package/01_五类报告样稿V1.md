# 五类报告样稿 V1

## 统一报告头

每份报告统一展示：报告名称、报告类型、统计周期、数据截止时间、生成时间、报告版本、数据来源状态（模拟/正式）、数据质量提示。

报告统一分为：本期摘要、核心指标、趋势或对比、业务分析、建议事项、数据和口径说明。

页面显示事实数据与AI分析时必须区分。没有数据、读取失败和真实为零分别展示。

---

## 一、客户经营分析报告（周报/月报）

### 1. 报告摘要

展示新增意向、期末意向、期末成交、期末流失、画像分布和需要关注的事项。

### 2. 客户状态总览

明细状态：新录入、跟进中、意向强烈、已签约、已入学、已流失。

汇总状态：
- 期末意向：新录入+跟进中+意向强烈；
- 期末成交：已签约+已入学；
- 期末流失：已流失。

每种状态显示数量和占比。占比分母为统计周期结束时的全部有效客户；有效客户指有有效手机号并进入客户主数据的客户。按手机号去重。

### 3. 本期新增及期末去向

| 去向 | 数量 |
|---|---:|
| 期末仍处于意向 | - |
| 期末已签约 | - |
| 期末已入学 | - |
| 期末已流失 | - |

四项合计等于本期新增意向客户数。回流客户不计入新增。

### 4. 项目画像

新加坡国际本硕升学计划、中德精英人才共建计划分别统计：符合、不符合、信息不足（含尚未完成研判子项）。分母为全部期末意向客户。两个项目独立统计，不能相加去重。

画像使用当前数据库最新有效研判结果；查看历史月份也按当前最新结果重算。报告需提示历史画像可能随研判更新变化。

### 5. 比较与趋势

周报默认与上一自然周比较；历史范围最多查看前一个月。月报默认与上一个自然月比较；用户选择历史月份后逐月展示，不合并多月总量。不选择时不展开额外历史趋势。

周报按周一至周日，月报按自然月，统一北京时间。

### 6. 下钻

网页可查看匹配客户：姓名、脱敏手机号、当前状态、来源渠道、负责员工、最新研判结果、必要跟进摘要。不展示完整画像依据。PDF只保留汇总。

## 二、员工日报汇总

### 1. 提交情况

按部门显示应提交、已提交、未提交人数。一期所有在职员工计入应提交范围，周一至周五要求提交，周末不计应交和未交；周末实际提交内容可进入工作汇总。

日报按所属业务日期统计；补交日报归回原日期。每日同一员工最多计一次有效提交。

### 2. 部门摘要

按部门展示主要进展、关键产出、潜在风险和其他工作记录。报告不展示个人日报原文，不评价个人绩效。AI无法可靠归类时进入其他工作记录或标记资料不足。

---

## 三、员工周报汇总

### 1. 每日提交明细与全周人次

展示周一至周五每天各部门应交、已交、未交人数，并展示全周应交、已交、未交人次。周末实际工作内容可纳入工作摘要，但不计入提交人次。

### 2. 部门周度汇总

展示本周主要进展、关键产出、未完成事项和主要风险。

### 3. 上周对比

按部门比较上周与本周的进展、风险、协调事项。数据不足时标记无法完整比较。不比较个人，不做部门评分，不依据日报数量推断绩效。

---

## 四、学生心理健康周报

### 1. 总体态势

展示本周覆盖学生数、整体心理态势、风险人数及周变化、考试/假期等背景和支持建议。

统计对象是本周有心理相关记录的学生；无记录不计入比例，也不视为正常。每名学生按一人统计，风险结果沿用学生模块识别结果。

### 2. 个案

网页中：MANAGER查看整体报告和授权个案；EMPLOYEE只能查看自己负责的个案；无负责关系员工不能查看；PROSPECT和STUDENT不能查看。

PDF只保留汇总，不包含姓名、联系方式和具体心理反馈。报告不展示通知确认、跟进状态和处理结果。高风险即时通知不等待周报。

---

## 五、投诉处理周报

### 1. 统计对象

沿用学生模块工单类型字段。类型为投诉纳入，建议/咨询排除。正式字段未完成时，模拟数据补充`feedback_type`。

### 2. 核心数据

展示新增投诉数、解决数、期末未解决数、超过七天未解决数、首次响应数量、未响应数量、平均首次响应时长、最长首次响应时长、满意/不满意/未评价。

首次响应时长=首次响应时间-提交时间；没有首次响应不参与平均和最长计算，单独显示未响应。

超过7×24小时仍未解决，标记长期未解决；从投诉提交时间起算。

### 3. 特别案例

AI低评分/高风险候选进入待复核；负责人复核通过后才是特别案例。网页特别案例只展示案例编号、负责人、处理进度。PDF只展示汇总和待复核候选数，不展示投诉人、原文、具体处理内容或未复核案例。

---

## 统一建议事项

一期只在报告中展示建议，不自动创建员工待办。建议可以人工补充负责部门、负责人和处理状态。

## 统一AI边界

程序负责周期、去重、数量、占比、趋势、时长和状态判断。AI只负责摘要、归纳、趋势文字、风险提示和支持性建议。AI不得编造数字、做未经证实的因果推断、评价个人绩效、做心理诊断或把未复核投诉认定为特别案例。AI失败时保留确定性统计。
