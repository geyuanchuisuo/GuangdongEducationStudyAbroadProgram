## 六、暂不阻塞一期的待确认项

1. 客户状态历史和精细转化路径的数据来源；一期只展示期末状态，不还原历史路径。
2. 部门负责人、建议事项负责人由谁指定；一期允许人工补充。
3. 心理风险响应时限、未响应升级机制和后续处置流程。
4. 真实投诉字段最终名称和正式人工复核流程。
5. 自动生成和调度机制；一期手动生成。
6. 报告正式数据接口字段；当前先用模拟数据，后续按统一结构替换。
